Projects
Project	What it shows	Headline result
UK rainfall–runoff benchmark	GR4J, GR6J (± snow module) and an LSTM ensemble compared on 128 UK catchments (CAMELS-GB), with maps of where each model performs best	The LSTM was best in 110 of 128 catchments, but adding a snow module closed 66–94% of its lead in the Cairngorms
Aire PDM flood forecasting	An hourly PDM forecasting system at 1–24 h lead times, plus a rating-curve review using live Environment Agency data	Updating cut the 3 h flood-peak forecast error from 23% to 4%; the largest flood flows carry up to 21% rating uncertainty
